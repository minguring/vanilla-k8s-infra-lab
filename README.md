## 아키텍처 개요
Azure 위에 **직접 구성하는 쿠버네티스(vanilla Kubernetes)** 실습 환경을 Terraform으로 정의한 프로젝트입니다.
관리형 서비스(AKS)를 쓰지 않고, VM 위에 클러스터를 직접 올려보며 내부 동작을 학습하는 것이 목적입니다.
